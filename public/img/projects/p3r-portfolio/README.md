# Capturas de P3R Portfolio

- Fuente: aplicación local, versión posterior a `a7aaa42`, capturada el 28/09/2026 en Brave headless.
- Viewport: 1440 × 1000, densidad 1, movimiento reducido para capturar escenas estables.
- `menu.webp`: menú principal, 87762 bytes.
- `social.webp`: ficha de Oguri en Social Link, 81452 bytes.
- Conversión de PNG a WebP con Sharp, calidad 85, sin recorte ni reescalado.
- Se ocultó únicamente el indicador de desarrollo de Next.js durante la captura.

Para actualizarlas: abrir una sesión local nueva, cerrar el splash, esperar fuentes e imágenes, capturar el menú y después Social Link. Mantener las dimensiones y actualizar los textos alternativos si cambia la composición. Las imágenes se comparten entre `app/data/projects.ts` y el README principal.
